# EDU_FinEng_RiskMgmt

Education repository for Coursera "Financial Engineering and Risk Management Specialization".

## Setup

* Use directories to reflect course hierarchy.
* Store data in `.md` files. They are gonna be easy to feed to AI in the future and can be stored locally.
* `images` directory to store images used in local `.md` files.
* `reading` directory to store `.pdf` or maybe links to reading materials related to local `.md` files data.

## Tips

* On Ubuntu use Drawing app from (Ken VanDine (ken-vandine)) to highlight / mark things on images.
